# Виправлення PageSpeed для aaukraine.org

## Діагноз (перевірено напряму на домені)

Домен aaukraine.org віддає React/SSR-збірку цього проєкту. Основні проблеми швидкості на мобільному:

1. **Блокуючі шрифти** — Google Fonts підключено як звичайний `<link rel="stylesheet">` у `<head>`. Браузер зупиняє рендеринг, поки CSS шрифтів не завантажиться. Плюс важкий змінний шрифт Fraunces (opsz 9–144).
2. **JavaScript-гідратація** — сторінка повністю статична за змістом, але віддає повний React-бандл; мобільний пристрій витрачає час на завантаження та виконання JS.
3. **Зображення og-image** на storage.googleapis.com (не критично для рендерингу, але PageSpeed може це позначати).

## Що зробимо

1. Шрифти: додати `media="print" onload="this.media='all'"` (або preload) для stylesheet Google Fonts у `src/routes/__root.tsx`, щоб вони не блокували перший рендер; звузити набори ваг (Fraunces 500;600 замість 400–600, IBM Plex Mono тільки 400) — менше файлів шрифтів.
2. Метрику LCP покращимо тим, що критичний CSS лишається вбудованим; додаткових великих ресурсів немає.
3. Не чіпаємо жоден текст, дизайн або секції — лише завантаження ресурсів.
4. Після публікації перевіряємо повторно PageSpeed і далі за результатами (майже напевно залишиться JS-гідратація — тоді опція: статичний HTML-експорт замість React-збірки).

## Технічні деталі

- Файл: `src/routes/__root.tsx`, масив `links` у `head()`.
- Мінімальна правка; жодних змін контенту.
- Альтернатива (якщо бали лишаться низькими): завантажувати на aaukraine.org статичний `index.html` (як у минулому пакуванні для хостингу) — це повністю прибирає JS-проблему, але вимикає живий AI-чат.
